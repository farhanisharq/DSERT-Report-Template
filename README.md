I made this Typst template to write up my MSc dissertation. This repository compiles to what is shown in `main.pdf`.

1. Add in your project amd personal details in `\sections\title.typ`
2. Place Typst files in `\sections` and images in `\images`
    - Link your Typst files in `main.typ`
3. Link in your .bib file in `main.typ`
4. Compile `main.typ`
